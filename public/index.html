    Pega la URL de tu compañero y le llega el cuerpo que todos aceptamos: { "name", "message" }. Si la URL no lleva ruta, se buscan las habituales (/inbox, /mensajes, /send-message…) y, si el destino es una página web, se lee su propio JavaScript para averiguar en qué ruta escucha. Si ya sabes la ruta, escríbela y se usa esa: https://su-url.ngrok-free.dev/mensajes. El botón Probar te dice qué hay en la URL antes de enviar.
